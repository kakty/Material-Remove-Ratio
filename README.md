# Material Remove Rate

A Python application for surface height analysis.

## Features

- Import ASC files
- Visualize surface data
- Compute height using different methods

## Installation

1. Install dependencies:
   ```
   pip install -r requirements.txt
   ```

2. Run the application:
   ```
   python main.py
   ```

## Usage

1. Click "1. 导入 ASC 文件" to load an ASC file.
2. Select a height computation method.
3. Click "2. 可视化" to visualize the surface.
4. Click "3. 高度计算" to compute height.

## Troubleshooting

- Ensure matplotlib is installed.
- ASC files should be in the correct format.
